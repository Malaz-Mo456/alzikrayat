# Alzikrayat

A photo sharing web application built with a custom MVC architecture, allowing users to upload, view, comment on, like, and tag photos.

## Technologies

- PHP 8
- MySQL
- PDO
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Custom MVC
- Custom Regex Router

## How to Run

1. Install XAMPP
2. Place the project folder in `C:\xampp\htdocs\alzikrayat`
3. Create a database named `alzikrayat` in phpMyAdmin
4. Import the SQL file located at `database.sql`
5. Start Apache and MySQL in XAMPP Control Panel
6. Open `http://localhost/alzikrayat/public/` in the browser
